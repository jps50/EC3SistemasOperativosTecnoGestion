# Arquitectura del sistema

Esta carpeta contiene el diagrama de arquitectura de la infraestructura virtualizada de TecnoGestión S.A.C.

Componentes:
- Windows y Oracle VirtualBox.
- Ubuntu Server 26.04.1 LTS.
- Adaptadores NAT y Host-Only.
- Servicios Samba, OpenSSH, UFW y cron.
- Administración de usuarios, grupos y permisos.
- Sistema de respaldos mediante rsync.
