# Evidencias de implementación

Esta carpeta contiene las capturas de pantalla obtenidas durante la implementación y validación del servidor virtualizado de TecnoGestión S.A.C.

## Organización de evidencias

- **01-instalacion:** VirtualBox, Ubuntu Server y configuración inicial.
- **02-usuarios-permisos:** Creación de usuarios, grupos y permisos.
- **03-samba:** Instalación, configuración y acceso desde Windows.
- **04-seguridad:** Firewall UFW y conexiones SSH.
- **05-rendimiento:** Monitoreo y pruebas con stress-ng y mpstat.
- **06-respaldos:** Copias de seguridad, restauración y automatización mediante cron.
- **07-recuperacion:** Interrupción y recuperación del servicio Samba.

Todas las evidencias corresponden a pruebas realizadas en un entorno virtualizado de laboratorio.
